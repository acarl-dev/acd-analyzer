# M1.5.1 - Analysis Dashboard / Frontend Integration - Implementierung

## Übersicht
Vollständige Implementierung der Tab-basierten Crawl-Detail-Ansicht mit dedizierten API-Endpunkten für alle Analyzer-Daten.

## Backend (Laravel)

### Neue API-Controller (8 neue)
- **CrawlRunOverviewController** - Dashboard-Übersicht mit Metriken
- **CrawlRunPagesController** - Seiten-Liste und Detail-Ansicht
- **CrawlRunIssuesController** - Issue-Filterung und Gruppierung
- **CrawlRunLinksController** - Link-Analyse (href vs normalized)
- **CrawlRunRedirectsController** - Redirect-Chains
- **CrawlRunRobotsTxtController** - robots.txt Daten
- **CrawlRunSitemapsController** - Sitemap-Tree mit paginierten URLs
- **CrawlRunCanonicalsController** - Canonical-Status-Analyse

### API-Endpunkte
```
GET /api/crawl-runs/{crawlRun}/overview
GET /api/crawl-runs/{crawlRun}/pages
GET /api/crawl-runs/{crawlRun}/pages/{pageId}
GET /api/crawl-runs/{crawlRun}/issues
GET /api/crawl-runs/{crawlRun}/links
GET /api/crawl-runs/{crawlRun}/redirects
GET /api/crawl-runs/{crawlRun}/robots-txt
GET /api/crawl-runs/{crawlRun}/sitemaps
GET /api/crawl-runs/{crawlRun}/sitemaps/{sitemapId}
GET /api/crawl-runs/{crawlRun}/canonicals
```

### Datenbankmodelle
- Website.php: Neue Relationships zu RobotsTxt und Sitemap

## Frontend (Next.js + TypeScript)

### TypeScript Types (types/crawl.ts)
11 neue Interfaces für strukturierte API-Responses:
- CrawlRunOverview
- PageListItem, PageDetail
- IssueItem, IssueGroupItem
- LinkItem
- RedirectItem
- RobotsTxtData
- SitemapItem, SitemapUrl
- CanonicalItem

### API Client (api/crawl.ts)
9 neue Funktionen passend zu Backend-Endpunkten

### Tab-Komponenten (8 Tabs)

1. **OverviewTab** - Dashboard mit Health Score
   - 10 Metrik-Karten (Seiten, Issues, Links, Redirects, etc.)
   - Health Score Berechnung

2. **PagesTab** - Suchbare Seiten-Tabelle
   - URL-Suche
   - Status, Title, H1, Canonical, Redirects, Issues pro Seite

3. **IssuesTab** - Issue-Management
   - Filter nach Severity
   - Gruppierung nach Code mit Counts
   - Expandable Liste betroffener Seiten

4. **LinksTab** - Link-Analyse
   - Filter: All / Internal / External
   - Zeigt raw href vs normalized URL
   - Source Page Tracking

5. **RedirectsTab** - Redirect-Visualisierung
   - Summary Cards (Total, Max Hops)
   - Expandable Redirect-Chains mit Status Codes

6. **RobotsTxtTab** - robots.txt Anzeige
   - Status-Section
   - Sitemaps-Liste
   - Rules organisiert nach User-Agent
   - Collapsible Raw Content

7. **SitemapsTab** - Sitemap Explorer
   - Tree-Struktur mit Parent/Child
   - Click zum Laden paginierter URLs
   - Pagination UI (50 per page)
   - Zeigt URL vs Normalized URL

8. **CanonicalsTab** - Canonical-Status
   - 7 Summary Cards für Status-Typen
   - Filter-Buttons
   - Tabelle mit color-coded Status

### Haupt-Komponente
**CrawlResultTabs** - Tab-Navigation und Content-Container
- 9 Tabs (inkl. Technologies mit existierender CrawlTechnologySummary)
- Active Tab State Management
- Lazy Loading pro Tab

### Integration
**CrawlerDashboard** - Aktualisiert
- Import geändert von `CrawlResult` zu `CrawlResultTabs`
- Bestehende Funktionalität erhalten

## Features

### Datenvergleiche
- **href vs normalized URL** (Links)
- **requested URL vs final URL** (Redirects)
- **raw canonical href vs normalized canonical URL** (Canonicals)

### Pagination
- Sitemaps Tab: Unterstützt große Sitemap-Dateien (10,000+ URLs)
- Backend: Query-Parameter `page` und `perPage`

### User Experience
- Lazy Loading: Daten werden nur geladen wenn Tab aktiv
- Local State: Jeder Tab managed eigenen Loading/Error State
- Consistent UI: Alle Tabs folgen einheitlichem Design-Pattern
- Responsive: Tailwind CSS Grid/Flex Layout

### Fehlerbehandlung
- Try/Catch in allen API-Calls
- Loading States
- Error Messages
